# 第一讲 计算机视觉（RM 自瞄检测基础）

## 1. 什么是计算机视觉
CV 没有统一排他的标准定义，三个权威来源：
1. 斯坦福 CS231A：研究使机器从图像、视频等视觉数据中提取有用信息，进而实现对世界的解释与理解的工具与理论。
2. IEEE Technology Navigator：AI 与电气工程中的研究领域，致力于使机器从图像、视频及其他视觉输入中提取有意义的信息。
3. Szeliski《Computer Vision: Algorithms and Applications》：研究如何利用计算方法，从一幅或多幅图像中推断、描述和重建现实世界及其属性的科学领域。

共同点：从视觉观测中获取有用信息，并利用这些信息进行分析、推断或理解。

## 2. CV 研究什么
- 视觉观测：图像、视频、深度图、双目图像、多光谱图像等。
- 目标信息层次：类别识别、二维定位、三维位姿、运动状态估计。
- 典型问题：图像分类、目标检测、图像分割、关键点检测、深度估计、位姿估计、目标跟踪、三维重建。

核心思想：对明确任务选择合适的视觉观测，用算法滤除无关信息，对留下的信息进行分析。

## 3. RM 中的视觉与自瞄
自瞄流程：
图像及采集时间 → 检测（类别、图像位置、特征点）→ 位姿解算（目标相对相机位姿）
→ 坐标变换（结合云台姿态统一坐标）→ 跟踪与状态估计 → 瞄准与开火判定 → 通信交给电控。

本讲聚焦检测：输入相机原始图像，输出装甲板灯条四个角点像素坐标。

## 4. 相机成像与图像形成
- 光与传感器：灯条主动发光，数字与金属反射环境光。亮度颜色由光源、材质、观察方向、相机响应共同决定。改变照明、角度或曝光，像素值分布会明显改变。
- 焦距：影响视场与成像尺度，RM 常用定焦 6mm / 8mm。
- 对焦与光圈：对焦决定清晰物距范围；光圈数约等于焦距除以入瞳直径，光圈数小则进光多、景深浅。
- 曝光与运动模糊：拖影长度 L ≈ v_p * T。v_p=1200 像素/秒时，5ms 曝光约 6 像素拖影，1ms 约 1.2 像素。缩短曝光减轻模糊但画面变暗。
- 增益与噪声：增益放大信号但不增加光子数，噪声同时被放大。
- 全局快门 vs 滚动快门：全局快门整幅同时曝光；滚动快门逐行曝光，快速运动产生倾斜弯曲畸变。二者成因不同。

## 5. 数字图像的表示
- 像素与坐标：宽为列，高为行。左上角为原点，x 向右，y 向下，从 0 开始，坐标写作 (x, y)。
- 通道：灰度图单通道；彩色图三通道，OpenCV 读取顺序为 BGR。
- 数值类型：8 位无符号整数，0~255，每通道一字节。CV_8UC3 三通道，CV_8UC1 灰度。
  1920*1080 三通道 8 位图像像素数据 = 1920*1080*3 = 6220800 字节 ≈ 6.2 MB。
